# SmartDesk React + Vite Starter

Extracted from the uploaded Stitch export.

## Included
- React 18 + Vite + Tailwind CSS configuration
- Reusable layout and UI components
- Seven page implementations and React Router routes
- SmartDesk design tokens
- Original Stitch HTML previews and screenshots in `design-reference/`

## Run locally
1. Extract this ZIP.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.

## Integration notes
- The screens currently use sample/mock values and UI-level interactions.
- The starter is not connected to the existing Django REST API yet.
- Login is a visual/demo flow, not production authentication.
- AI analysis actions are demonstrations until connected to the backend.
- `index.html` and `vite.config.js` were added because the embedded source lists them but does not provide code blocks for them.
- Keep the existing Django `backend/` directory unchanged during integration.
